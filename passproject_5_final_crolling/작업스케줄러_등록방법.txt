========================================
Windows 서버 작업 스케줄러 등록 방법
========================================

이 파일은 Windows 서버에 PASSPROJECT5_FINAL_5 작업을 등록하는 방법을 안내합니다.

## 방법 1: 배치 파일 사용 (가장 간단) ? 권장

1. register_scheduler.bat 파일을 마우스 우클릭
2. "관리자 권한으로 실행" 선택
3. 자동으로 작업 스케줄러에 등록됩니다!


## 방법 2: PowerShell 직접 실행

1. PowerShell을 관리자 권한으로 실행
2. 프로젝트 폴더로 이동:
   cd [스크립트 파일이 있는 폴더 경로]
   (예: cd C:\ssafy\passproject-5-final\passproject_5_final_crolling)

3. 실행 정책 변경 (최초 1회만):
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

4. 스크립트 실행:
   .\register_scheduler.ps1


## 등록 확인 방법

1. 작업 스케줄러 열기:
   - 시작 메뉴에서 "작업 스케줄러" 검색
   - 또는 Win+R -> taskschd.msc 입력

2. 작업 스케줄러 라이브러리에서 "PASSPROJECT5_FINAL_5" 작업 확인


## 작업 설정 정보

- 작업 이름: PASSPROJECT5_FINAL_5
- 실행 시간: 매일 새벽 3시 (03:00)
- 실행 파일: PASSPROJECT5_FINAL_5.py
- 실행 권한: 최고 수준 권한


## 작업 수정/삭제 방법

### PowerShell에서 삭제:
Unregister-ScheduledTask -TaskName "PASSPROJECT5_FINAL_5" -Confirm:$false

### GUI에서 수정:
1. 작업 스케줄러 열기
2. "PASSPROJECT5_FINAL_5" 작업 우클릭
3. "속성" 선택하여 수정
4. "삭제" 선택하여 제거


## 주의사항

1. 서버가 24시간 켜져 있어야 정상적으로 실행됩니다.
2. Python과 필요한 라이브러리(schedule 등)가 설치되어 있어야 합니다.
3. 서버의 시간대 설정을 확인하세요 (한국 시간 KST 기준).


## 문제 해결

### "Python을 찾을 수 없습니다" 오류
- Python이 PATH에 등록되어 있는지 확인
- 또는 register_scheduler.ps1 파일에서 Python 경로를 직접 수정

### "관리자 권한이 필요합니다" 오류
- 배치 파일을 마우스 우클릭 -> "관리자 권한으로 실행" 선택

### 작업이 실행되지 않는 경우
- 작업 스케줄러에서 작업의 "마지막 실행 결과" 확인
- "PASSPROJECT5_FINAL_5.py" 파일이 서버에 있는지 확인
- 로그 파일이 생성되는지 확인
